# TaskFlow

Умный таск-менеджер с AI-разбором задач, заметками, календарём и синхронизацией через Firebase. PWA — можно установить на телефон.

## Структура

- `index.html` — всё приложение (HTML/CSS/JS), без сборки
- `api/parse-task.js` — серверная функция (Vercel), проксирует запрос к Anthropic API и держит ключ вне браузера
- `manifest.json`, `sw.js`, `icon-*.png` — PWA-манифест, service worker, иконки
- `firestore.rules` — правила безопасности Firestore (см. ниже)

## Деплой на Vercel

1. Залогинься: `vercel login`
2. Из корня проекта: `vercel` (для preview) или `vercel --prod` (в прод)
3. В настройках проекта на vercel.com добавь переменную окружения **`ANTHROPIC_API_KEY`** (Settings → Environment Variables) — без неё AI-разбор задач не будет работать. Ключ никогда не должен попадать в клиентский код.

## Firebase

Приложение использует Firestore для синхронизации между устройствами и Firebase Anonymous Auth для идентификации пользователя (вместо случайного ID в localStorage).

Перед первым использованием в проде:
1. В Firebase Console → Authentication → Sign-in method — включи **Anonymous**.
2. В Firebase Console → Firestore → Rules — вставь содержимое `firestore.rules` из этого репозитория и опубликуй. Без этого шага данные всех пользователей приложения читаемы/перезаписываемы кем угодно, у кого есть публичный `apiKey` (он всегда виден в клиентском коде — это нормально для Firebase, но правила обязаны ограничивать доступ по `request.auth.uid`).

## Локальный запуск

Статический сайт, достаточно любого http-сервера в корне репозитория, например:

```
npx serve .
```

Для локальной работы `api/parse-task.js` используй `vercel dev` вместо обычного статического сервера.
