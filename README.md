# TaskFlow

Умный таск-менеджер с разбором задач на естественном языке, заметками, календарём и синхронизацией через Firebase. PWA — можно установить на телефон.

## Структура

- `index.html` — всё приложение (HTML/CSS/JS), без сборки. Разбор текста задачи ("AI") — локальный JS-эвристический парсер (`parseTaskLocal`), без внешних API и ключей
- `manifest.json`, `sw.js`, `icon-*.png` — PWA-манифест, service worker, иконки
- `firestore.rules` — правила безопасности Firestore (см. ниже)

## Деплой на Vercel

1. Залогинься: `vercel login`
2. Из корня проекта: `vercel` (для preview) или `vercel --prod` (в прод)

Внешних переменных окружения / платных API не требуется.

## Firebase

Приложение использует Firestore для синхронизации между устройствами и Firebase Email/Password Auth — вход по email+паролю, чтобы один и тот же аккаунт открывался на любом устройстве (в отличие от Anonymous Auth, которая выдаёт новый ID на каждом устройстве и не позволяет синхронизироваться между ними).

Перед первым использованием в проде:
1. В Firebase Console → Authentication → Sign-in method — включи **Email/Password**.
2. В Firebase Console → Firestore → Rules — вставь содержимое `firestore.rules` из этого репозитория и опубликуй. Без этого шага данные всех пользователей приложения читаемы/перезаписываемы кем угодно, у кого есть публичный `apiKey` (он всегда виден в клиентском коде — это нормально для Firebase, но правила обязаны ограничивать доступ по `request.auth.uid`).

Без входа приложение работает локально на одном устройстве (кнопка «Продолжить без входа»), но без синхронизации между устройствами.

## Локальный запуск

Статический сайт, достаточно любого http-сервера в корне репозитория, например:

```
npx serve .
```
